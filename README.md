# 💎 CryptoDesk — Crypto Portfolio Dashboard

A modern, fully responsive cryptocurrency portfolio dashboard built with **React**, **Vite**, and **Chakra UI**. Track portfolio value, monitor wallet balances, view transaction history, and get support — all in one clean interface. Built with **React 18**, **React Router v6**, and a custom **Chakra UI design system**.

## ✨ Features

- 📊 **Portfolio overview** — Total value in INR + wallet balances in BTC and INR
- 📈 **Interactive price chart** with tabbed time ranges (1H · 1D · 1W · 1M)
- 💸 **Transaction history** — Tabbed view (All / Deposits / Withdrawals / Trades)
- 🔍 **Live search** across transactions
- 🏷️ **Status badges** — Pending · Processing · Completed · Cancelled with color coding
- 📥 **Export CSV** action for transaction data
- 🛟 **Support page** with contact form + live chat CTA
- 🌓 **Dark / Light theme toggle** *(persisted via `localStorage`)*
- 📱 **Fully responsive** — Fixed sidebar on desktop, drawer on mobile
- 🎨 **Custom design system** — Brand purple, custom text styles (`h1`–`h6`), responsive font sizes
- ♿ **Accessible** — Semantic HTML, ARIA labels on icon-only buttons
- ⚡ **Zero backend** — All data is mocked; UI is fully wired for future API integration

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| **Framework** | React 18 |
| **Build Tool** | Vite 4 + SWC |
| **UI Library** | Chakra UI v2 |
| **Styling** | Emotion (via Chakra) + Custom Theme |
| **Routing** | React Router v6 |
| **Icons** | React Icons |
| **Animations** | Framer Motion |
| **Fonts** | Ubuntu via `@fontsource/ubuntu` |
| **Linting** | ESLint |
| **Hosting** | Vercel / Netlify *(GitHub Pages also supported)* |
